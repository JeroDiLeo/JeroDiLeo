## 🌟 Proyectos destacados

### 📚 apuntesHUB: marketplace de apuntes con IA

Marketplace educativo full stack hecho para Ingeniería del Software 1, hoy en etapa beta. Los estudiantes compran y venden apuntes universitarios, organizados por universidad, materia y profesor.

- **Marketplace:** previsualización gratuita de las primeras páginas, lector de PDF integrado en el navegador (sin descargas obligatorias) y pagos con Mercado Pago.
- **Estudio con IA:** chat con los apuntes con citas a las páginas exactas, modo estudio con preguntas de práctica y búsqueda por temas.
- **Clases:** sección donde un profesor puede cobrar por clases, con contenido que se ve dentro de la plataforma sin posibilidad de descarga.
- **Seguridad:** diseñado para evitar que el material se filtre, con límites de sesiones por usuario y otras medidas de protección de contenido.
- **Mi foco:** backend y seguridad, incluyendo la base de datos, autenticación y autorización, protección de contenido y el pipeline de IA/RAG para PDFs.

**Tecnologías:** TypeScript, Next.js, Supabase (PostgreSQL), Vercel, Mercado Pago, GitHub Actions

🌐 Sitio: https://www.apunteshub.com/
🔗 Repo: https://github.com/nicorfalcon/apuntesHUB
